    A QUICK WALKTHROUGH

    Make your first batch.

    1. Open the door and pull a tray out.
    2. Choose a fruit and weight, then load it onto the tray.
    3. Insert the tray. Repeat for other trays if you like.
    4. Close the door and press Start drying.
    5. Change the sunlight to see temperature and evaporation respond.
    6. To remove fruit, open the door, pull the tray out and unload it.

    To mirror this in the phone app, open Smart Solar Dryer → Connect → HTML simulator and enter the six-digit code shown above. Both displays use the same backend simulation state.
